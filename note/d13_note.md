# 退化问题
- 网络并非越深越好，当网络加深层数过高时，模型的准确率不仅没有提升，反而急剧下降
- 根本原因在于：传统多层非线性变换层叠加后，梯度在反向传播时经过多层矩阵连续相乘，会导致梯度消失（Gradient Vanishing），深层的梯度根本传不到浅层
## 网络加深导致性能变差，是因为过拟合吗？
- 不是
- 过拟合（Overfitting）：Train Loss 非常低（拟合得很好），但 Val Loss 很大（泛化能力差）；网络退化（Degradation）：Train Loss 和 Val Loss 同时变高，这说明网络深了之后，连训练集都学不动了，根本无法收敛

# 残差学习（Residual Learning）
- 何恺明提出了一个思想：如果深层网络什么都学不会，那至少让它学会“恒等映射（Identity Mapping）”，即输出等于输入（），这样至少性能不会比浅层网络差
## 残差映射（Residual Mapping）
- 假设我们希望某几层拟合的目标函数是H(x)：传统网络：强行让卷积层直接去拟合H(x)。当H(x)接近恒等函数x时，极其繁琐且难以收敛；残差网络：我们将目标函数重构为H(x)=F(x)+x，其中F(x)=H(x)-x就是所谓的残差（Residual）
- 网络不再需要学习复杂的H(x)，而只需要学习残差F(x)
  
# ResNet中的两种基础残差块
- BasicBlock（用于 ResNet-18/34）：由 2 个3 * 3卷积组成
- Bottleneck（用于 ResNet-50/101/152）：由1 * 1，3 * 3，1 * 1卷积组成
