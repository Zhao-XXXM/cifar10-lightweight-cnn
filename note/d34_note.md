# Day34：均值、标准差与稳定性可视化
- Day33 使用相同数据划分和训练配置运行多个训练随机种子
- Day34 不再训练模型，而是把多个独立结果转换成统计证据
- 今天计算最佳 Val Acc 的均值、样本标准差、最小值、最大值、极差和变异系数
- 同时绘制单种子散点图、`mean +/- std` 误差棒和逐 Epoch 验证曲线

# 为什么不能只汇报最好的一次
- 随机种子会改变初始化参数和 Batch 顺序，训练结果存在自然波动
- 只汇报最高准确率属于选择性报告，会高估模型的典型表现
- 多种子均值更接近“重复训练时通常能达到的水平”
- 标准差描述结果围绕均值的波动程度，可以辅助判断稳定性
- 最低值和最高值也应保留，不能因为某次结果较差就随意删除

# 样本均值
- 三个种子的最佳验证准确率记为 `a_1、a_2、a_3`
- 样本均值为：`mean = (a_1 + a_2 + a_3) / 3`
- 均值使用所有独立实验，不偏向最好或最差的一次
- 论文和实验报告通常写成 `mean +/- std`

# 样本标准差
- 样本标准差为：`s = sqrt(sum((a_i - mean)^2) / (n - 1))`
- 分母使用 `n - 1`，因为这里只观察了有限个训练种子，并不是所有可能随机结果
- Python 的 `statistics.stdev` 默认计算样本标准差
- 如果使用 `statistics.pstdev`，分母是 `n`，含义是总体标准差，不适合当前小样本估计
- 标准差为 0 表示记录完全一致，不代表模型在所有环境中绝对稳定

# 极差与变异系数
- 极差为：`max - min`，单位仍然是准确率百分点
- 极差容易理解，但只由最高值和最低值决定
- 变异系数为：`CV = std / mean * 100%`
- CV 可以表达相对波动，但准确率接近 0 时不适合使用
- 本项目以 `mean +/- std` 为主，极差和 CV 作为辅助指标

# 如何阅读误差棒
- 蓝色散点表示每个训练种子的实际最佳 Val Acc
- 橙色点表示三个种子的均值
- 橙色误差棒上下各延伸一个样本标准差
- 误差棒不是单次预测的置信区间，也不能直接证明两个模型存在统计显著差异
- 当前只有一个宽度模型和三个种子，主要目标是描述稳定性，而不是进行显著性检验

# 验证曲线能补充什么信息
- 最终最佳准确率相近，不代表训练过程完全相同
- 逐 Epoch 曲线可以观察不同种子是否在相近轮次收敛
- 如果某个种子曲线剧烈震荡，可能需要检查学习率、Batch Size 或数据顺序敏感性
- 如果三条曲线趋势相似，说明训练过程具有一定一致性

# 代码拆解
- `load_records`：读取 Day33 汇总表，并要求至少两个独立种子
- `validate_records`：检查种子完整、宽度一致、数据划分哈希一致且官方 Test 未评估
- `statistics.mean`：计算多个种子的算术均值
- `statistics.stdev`：使用 `n - 1` 计算样本标准差
- `calculate_statistics`：统一计算均值、标准差、极差和变异系数
- `save_accuracy_plot`：绘制单次结果散点和 `mean +/- std`
- `save_validation_curves`：读取三个 history 并绘制验证准确率曲线

# 运行方式
- 先确认 Day33 正式结果存在：`checkpoints\day33_multiseed\summary.csv`

- 正式统计：`venv\Scripts\python.exe notecode\d34_seed_statistics.py`
- Day34 只读取已有 CSV 和 JSON，不重新训练模型，也不读取 CIFAR-10 图片

# 输出文件
- 输出目录：`checkpoints\day34_seed_statistics\`
- `statistics.csv`：各指标的均值、样本标准差、最小值、最大值、极差和 CV
- `statistics.json`：包含种子、宽度、划分哈希和统计结果的结构化报告
- `accuracy_stability.png`：单种子散点与 `mean +/- std` 图
- `validation_curves.png`：三个种子的 Validation Acc 曲线

# 实验结果记录
- Day33 三个种子的最佳 Val Acc 分别为 73.04%、75.34% 和 73.14%，最佳 Epoch 分别为 7、10 和 9
- 最佳 Val Acc 的均值为 73.84%，样本标准差为 1.30 个百分点，可写为 `73.84% +/- 1.30%`
- 最佳 Val Acc 的最小值为 73.04%，最大值为 75.34%，极差为 2.30 个百分点，变异系数约为 1.76%
- 最终 Val Acc 的均值为 73.57%，样本标准差为 1.54 个百分点；最佳 Epoch 的均值为 8.67，标准差为 1.53
- 三条验证曲线总体都在上升，但 `seed=42` 在第 6 轮出现回落，`seed=123` 在第 10 轮达到最高，说明收敛轨迹会受随机种子影响
- 训练时间均值约为 898.48 秒，标准差约为 115.81 秒，时间变异系数约为 12.89%；该波动还可能来自 CPU 负载和系统状态，不能全部归因于模型随机性
- Day32 中 `width_mult=1.5` 比 `1.0` 高 1.68 个百分点，但 Day34 中 `width=1.0` 的种子标准差已经达到 1.30 个百分点，因此不能仅凭单次宽度实验断言 `1.5` 稳定优于 `1.0`
- 当前统计只描述 `width_mult=1.0` 的 Validation 稳定性，官方 Test Acc 仍未评估
