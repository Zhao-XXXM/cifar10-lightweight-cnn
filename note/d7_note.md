# 训练看 Loss，评估看 Accuracy
- Loss（损失值）：是一个连续且可导的数学函数（如交叉熵）。因为梯度下降算法必须依靠“求导”来更新参数，所以训练阶段必须用 Loss。
- Accuracy（准确率）：离散且不可导：Accuracy = 预测正确的样本数/总样本数*100%

# 测试集必须用与训练集完全相同的transform
- 神经网络的权重矩阵  和偏置 ，是在“被标准化后的数据分布（均值为 0，方差为 1）”上学习出来的。

# 在对测试集进行评估时，代码中需加上两行保护罩
## model.eval()
- 将网络切换为评估/推理模式
- 网络中的某些特殊层在训练和测试阶段的行为是不一样的
## with torch.no_grad():
- 强行关闭PyTorch的自动求导与计算图构建机制
- 在测试阶段，只需要做前向传播算出预测结果，根本不需要做反向传播。关闭后可以节省大量的内存或显存占用，并提升计算速度

# GPU/CPU 并行原理
- predicted == labels 是并行向量化比较
- 它一次性把 64 个元素的向量送入 CPU/GPU 的并行计算单元，在 1 个时钟周期内就得到了 64 个布尔结果 [True, False, True, ...]
