# Depthwise Separable Convolution
- 普通卷积把“空间特征提取”和“通道信息融合”这两件事绑在一起完成
- Depthwise Separable Convolution 则把它拆成两步：先做逐通道空间卷积，再做 1 * 1 通道融合
- 这是一种非常经典的轻量化思路，也是 MobileNet 类模型的核心基础

# 普通卷积为什么贵
- 对于输入通道数为 `Cin`、输出通道数为 `Cout`、卷积核大小为 `K * K` 的普通卷积
- 参数量公式为：`Cin * Cout * K * K`
- 计算量也会随着 `Cin` 和 `Cout` 一起快速增长
- 当通道数较大时，3 * 3 卷积会成为模型中最主要的开销来源

# Depthwise 卷积
- Depthwise 卷积的做法是：每个输入通道单独使用一个卷积核做空间卷积
- 也就是说，一个通道只负责提取自己的空间纹理，不和别的通道混合
- 参数量公式：`Cin * K * K`
- 这一步只负责“看空间”，不负责“合通道”

# Pointwise 卷积
- Pointwise 卷积就是 1 * 1 卷积
- 它的作用是把 Depthwise 阶段得到的各通道特征重新组合起来
- 参数量公式：`Cin * Cout`
- 这一步只负责“混通道”，不负责复杂的空间卷积

# 深度可分离卷积的总参数量
- 总参数量 = Depthwise 参数量 + Pointwise 参数量
- 即：`Cin * K * K + Cin * Cout`
- 和普通卷积相比，少掉了直接在高维通道上做完整 K * K 卷积的巨大开销

# 参数量对比例子
- 假设 `Cin=64, Cout=128, K=3`
- 普通卷积参数量：`64 * 128 * 3 * 3 = 73728`
- 深度可分离卷积参数量：`64 * 3 * 3 + 64 * 128 = 8768`
- 压缩比例大约是 `73728 / 8768 ≈ 8.41`

# 实验代码说明
- 今天的代码里，普通卷积和深度可分离卷积都统一接了 `BN + ReLU`
- 这样比较更接近真实网络结构，也更公平
- 但是参数量下降的核心，依然来自卷积本身从“完整 3 * 3”拆成了“Depthwise + Pointwise”

# 为什么它能轻量化
- 普通卷积把空间提取和通道融合一次做完，计算很重
- Depthwise Separable Convolution 把任务拆开后，最贵的空间卷积只发生在单通道上
- 这会显著减少参数量和计算量，但也可能带来一定表达能力损失
- 轻量化不是简单减层，而是把“空间提取”和“通道融合”拆开做

# 什么时候特别有用
- 当模型部署在移动端、嵌入式设备或者算力有限的环境中时
- 当你希望在尽量少掉准确率的情况下压缩模型体积时
- 当你要做“轻量化 CNN 改进路线”时，它几乎是必讲知识点
