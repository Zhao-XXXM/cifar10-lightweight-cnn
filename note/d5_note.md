# Batch
- Batch 是一次送入模型同时计算的一批样本
- 代码中后续常用 `batch_size=64`，表示每次训练处理 64 张图片
- Batch 训练比一张一张训练更高效，也能让梯度估计更稳定

# Epoch 轮次
- Epoch 表示完整遍历整个训练集一轮
- CIFAR-10 训练集有 50000 张图，如果 batch_size=64，一个 Epoch 大约有 782 个 step
- 训练深度学习模型通常需要多个 Epoch 才能逐步收敛

# 池化
- 池化是把特征图切分成小块，从每个小块中选出一个代表值
- 代码中使用 `nn.MaxPool2d(kernel_size=2, stride=2)`
- 对 4x4 特征图做 2x2 最大池化后，输出尺寸会变成 2x2

## 最大池化
- MaxPool 会取每个局部窗口中的最大值
- 最大值通常代表该局部区域中最强的特征响应
- 例如某个区域检测到明显边缘，最大池化会保留这个强响应

## 池化的作用
- 降低特征图尺寸，减少后续计算量
- 扩大后续神经元的感受野
- 获得一定平移不变性，即目标轻微移动时模型仍能识别
- 对噪声和局部扰动有一定抑制作用

# SimpleCNN 结构
- 第一组：`Conv2d(3, 16, 3, padding=1) -> ReLU -> MaxPool2d`
- 第二组：`Conv2d(16, 32, 3, padding=1) -> ReLU -> MaxPool2d`
- 输入图像尺寸变化：`3x32x32 -> 16x16x16 -> 32x8x8`
- 分类头使用 `Linear(32 * 8 * 8, 10)` 输出 10 个 CIFAR-10 类别的 logits

# 展平操作
- `x.view(x.size(0), -1)` 表示保留 Batch 维度，把通道、高、宽三个维度拉平成一维向量
- 对 SimpleCNN 来说，展平后每张图片变成 `32 * 8 * 8 = 2048` 维
- 展平之后才能送入全连接分类层

# CIFAR-10 数据集
- CIFAR-10 是 10 类 32x32 彩色图像分类数据集
- `transforms.ToTensor()` 会把图片转成 Tensor，并把像素值缩放到 `[0, 1]`
- 数据集中标签是数字，需要通过 `classes[label]` 映射为类别名
