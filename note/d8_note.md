# Batch Normalization (批归一化)
## BN层的处理为四个步骤
- 计算当前Batch的均值
- 计算当前Batch的方差
- 极值标准化：将数据拉回到“均值为0，方差为1”的标准正态分布
- 仿射变化：如果强制把所有特征都限制在标准正态分布，会破坏卷积层学到的特征表达能力。因此，BN引入了两个可学习参数γ（缩放）和β（平移）。在训练过程中，神经网络会通过反向传播自动学习出最适合当前特征分布的 γ和β。
## 为什么必须加上BN？
- 解决内部协变量偏移：网络深层节点的输入分布不再随浅层参数更新而剧烈波动，使得深层网络可以安心学习
- 允许使用更大的学习率：BN 规范了梯度的量级，防止梯度爆炸，从而可以让学习率提高数倍，极大加快模型收敛速度
- 降低对参数初始化的敏感度：哪怕权重初始化选得不够好，BN 也能强行把数据拉回合理区间
- 自带轻微的正则化效果：因为每个 Batch 的均值和方差都带有随机噪声，这相当于给网络输入引入了微小的扰动，在一定程度上能减轻过拟合

# nn.BatchNorm2d(num_features=16)
- 对 2D 图像特征图做批归一化
- num_features 必须严格等于上一层卷积输出的通道数（out_channels）
## 为什么按通道做归一化？
- 对于形状为 (Batch, Channel, Height, Width) 的特征图，BN 会在 (Batch, Height, Width) 这三个维度上共同计算出 1 个均值和 1 个方差。也就是说，每个通道拥有独立的一组 γ和β参数
- 卷积核的物理意义：一个通道=一种特征检测器：我们希望同一个特征检测器在所有空间位置以及所有样本上输出的特征图，都遵循相同的数值分布
- 数学统计过程：N * H * W汇聚成1个均值：相当于用这一批数据中的N * H * W个数值，为这个通道算出一对统一的均值和方差
