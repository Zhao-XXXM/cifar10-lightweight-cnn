# Day31：规范划分 Train、Validation 和 Test
- Day31 不训练模型，先修正最终实验的数据使用协议
- 当前 CIFAR-10 官方训练集有 50,000 张图片，官方测试集有 10,000 张图片
- 今天把官方训练集按类别分层划分为 45,000 张训练数据和 5,000 张验证数据
- 官方测试集保持独立，只在模型结构和超参数确定后用于最终评估

# 三种数据集的职责
- Train Set：参与前向传播和反向传播，用于更新模型参数
- Validation Set：不更新参数，用于选择最佳 Epoch、比较模型结构和调整超参数
- Test Set：不参与模型选择，只用于报告最终泛化性能
- 如果使用 Test Acc 反复选择模型，测试集信息就会间接影响研究决策，最终准确率会偏乐观

# 当前项目为什么需要修正
- Day28 的训练脚本把 CIFAR-10 官方测试集命名为 `test_loader`，但每个 Epoch 都用它计算 `val_acc`
- `val_acc` 又被用于保存最佳 checkpoint，因此官方测试集实际上承担了验证集职责
- Day29 和 Day30 也进一步观察了官方测试集上的类别错误和单样本预测
- 这些结果不删除，它们仍然是有价值的探索性实验，但最终报告必须明确标记为“探索阶段结果”
- 从 Day31 开始建立规范协议，最终模型通过 Validation Set 选择，再单独计算 Test Acc

# 什么是数据泄漏
- 数据泄漏是指训练或模型选择过程使用了本应不可见的测试信息
- 直接把测试图片加入训练集属于明显泄漏
- 根据 Test Acc 选择模型、Epoch 或超参数也属于间接泄漏
- 测试集使用次数越多，研究者越可能无意中针对测试集进行优化
- 正确做法不是完全不看测试集，而是在模型方案确定后再进行一次正式评估

# 分层划分的原理
- 普通随机划分只控制总样本数，不保证每个类别数量完全一致
- 分层划分先按照类别收集索引，再从每个类别中抽取相同数量的验证样本
- CIFAR-10 官方训练集每类有 5,000 张图片
- 每类抽取 500 张作为验证集，剩余 4,500 张作为训练集
- 因此训练集为 `4,500 * 10 = 45,000`，验证集为 `500 * 10 = 5,000`
- 官方测试集每类有 1,000 张，总计 10,000 张

# 随机种子与可复现性
- 分层划分仍然需要随机打乱每一类的样本索引
- `random.Random(seed)` 创建只属于划分过程的随机数生成器
- 相同种子和相同数据必须生成完全相同的训练/验证索引
- 不同种子会改变具体样本，但每类数量仍保持 4,500/500
- 代码对完整索引计算 SHA-256；相同划分的哈希必须一致

# 为什么保存索引
- 只记录“随机种子为 42”还不如直接保存索引可靠
- 保存索引后，Day32 及后续实验可以加载完全相同的训练集和验证集
- 不同模型必须复用同一份划分，才能保证差异主要来自模型结构
- `split_indices.json` 同时保存划分参数、样本数量、哈希和具体索引

# 代码拆解
- `stratified_split`：按类别收集索引，每类固定抽取验证样本
- `validate_split`：检查索引无重复、Train/Val 无交集并完整覆盖 50,000 张训练图片
- `count_by_class`：统计 Train、Val 和 Test 中每个类别的数量
- `split_hash`：把训练和验证索引转换为紧凑 JSON，再计算 SHA-256
- `save_class_distribution`：把每个类别的样本数量保存为 CSV
- `random.Random(seed)` 不会修改训练脚本中的全局随机状态

# 运行方式
- 语法检查：`venv\Scripts\python.exe -m py_compile notecode\d31_data_split.py`
- 生成正式划分：`venv\Scripts\python.exe notecode\d31_data_split.py --seed 42`
- 测试其他种子：`venv\Scripts\python.exe notecode\d31_data_split.py --seed 123`
- 正式实验统一使用 `seed=42` 的数据划分，不要在看到模型结果后更换划分种子

# 输出文件
- 正式划分目录：`checkpoints\day31_data_split\seed_42\`
- `split_indices.json`：训练和验证索引、划分参数及 SHA-256
- `class_distribution.csv`：各类别在 Train、Val 和 Test 中的数量
- 其他种子会保存到各自目录，不会覆盖正式划分
