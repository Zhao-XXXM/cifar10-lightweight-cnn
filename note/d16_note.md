# 强化训练
- Day16 在 ResNet-18 训练中加入数据增强、Weight Decay 和学习率调度
- 目标是提升泛化能力，而不是单纯增大模型
- 这一步开始进入更接近真实实验的训练策略设计

# 数据增强
- 数据增强是在训练阶段对图片做随机变换，让模型每个 Epoch 看到略有不同的样本
- Day16 使用 `RandomCrop(32, padding=4)` 和 `RandomHorizontalFlip()`
- 这可以扩大训练数据的变化范围，减少模型死记硬背训练集

# RandomCrop
- `RandomCrop(32, padding=4)` 会先在图片周围补 4 个像素，再随机裁剪回 32x32
- 它模拟目标在图像中轻微平移的情况
- 对 CIFAR-10 这种小图像分类任务非常常用

# RandomHorizontalFlip
- `RandomHorizontalFlip()` 会以默认概率 0.5 随机水平翻转图片
- 对飞机、车、猫、狗等类别，水平翻转通常不会改变类别语义
- 但不是所有任务都适合翻转，例如文字识别或方向强相关任务

# 训练集和测试集 transform 不同
- 训练集使用随机增强，提高模型鲁棒性
- 测试集只使用 `ToTensor + Normalize`，保证评估结果稳定可复现
- 测试阶段不能随机裁剪或随机翻转，否则每次评估结果都会受到随机性影响

# Weight Decay
- `weight_decay=5e-4` 是 L2 正则化的一种工程实现
- 它会惩罚过大的权重，让模型参数不要无限变大
- 权重更平滑时，模型通常更不容易过拟合

# 学习率余弦退火
- `CosineAnnealingLR` 会让学习率按照余弦曲线逐渐下降
- 训练前期保持较大学习率，帮助模型快速探索参数空间
- 训练后期学习率变小，有助于模型在较优区域附近精细收敛
- `T_max=EPOCHS` 表示一个完整余弦周期覆盖全部训练轮数

# scheduler.step()
- 每个 Epoch 结束后调用 `scheduler.step()` 更新学习率
- 代码中先通过 `scheduler.get_last_lr()[0]` 记录当前学习率，再执行更新
- 打印 LR 可以帮助确认学习率调度器是否真的生效

# 实验意义
- Day15 是 ResNet18 基础训练
- Day16 是 ResNet18 强化训练
- 二者可以构成一个对照实验，用来分析数据增强、正则化和学习率调度对泛化能力的影响
